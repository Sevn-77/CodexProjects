# Creator OS Bug 记录

根据项目现有检查记录和本次实际运行结果整理。仅列出有依据的问题；潜在风险和未验证项目单独标注。

## 已确认并修复

### BUG-001：README 的备用服务命令监听所有网络接口

- **严重程度：** 低
- **发现依据：** 初次检查发现 README 的 `python -m http.server 8000` 未设置绑定地址。Python HTTP 服务默认可能接受本机网络接口上的连接；项目定位为个人本地工具。
- **原因：** README 手动启动命令与 Windows 启动脚本的本机限制不一致。
- **修复：** 将 README 命令改为 `python -m http.server 8000 --bind 127.0.0.1`。
- **验证：** 使用同一绑定参数在临时端口启动本地服务并请求首页，实际收到 HTTP 200；同时检查 README 与 `.bat` 都包含 `--bind 127.0.0.1`。
- **状态：** 已修复。

### BUG-002：浏览器请求网站图标时得到 404

- **严重程度：** 低（不影响主要功能）
- **发现依据：** 用户提供的本地服务日志记录了 `GET /favicon.ico` 返回 404。
- **原因：** 页面没有声明站点图标，浏览器回退请求默认图标路径。
- **修复：** 新增本地 `favicon.svg`，并在 `index.html` 中声明该图标。
- **验证：** 自动化测试检查 HTML 图标引用和文件存在；本地 HTTP 请求实际返回 HTTP 200，内容类型为 `image/svg+xml`。本次没有采集浏览器网络日志，因此只确认图标资源可用，不声称已单独观测默认路径请求消失。
- **状态：** 已修复并验证图标资源可访问。

## 潜在风险（未复现）

- 浏览器 `localStorage` 不可用或空间不足时，保存操作可能失败。当前实现没有显示专门的存储失败提示；本次没有模拟浏览器禁用存储或配额耗尽。
- JSON 备份目前只支持导出，README 已明确记录尚无导入功能。这是当前版本范围限制，不属于已确认的运行 Bug。
